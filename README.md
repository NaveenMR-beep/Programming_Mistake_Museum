# 🐛 Programming Mistake Museum

A Python desktop application that helps programmers store, analyze, and learn from their programming mistakes.

Instead of forgetting errors after fixing them, users can save their mistakes and solutions in a personal "museum" for future learning.

---

## 🚀 Features

- ➕ Add programming mistakes
- 📋 View all mistakes
- 🔍 Search mistakes
- ✏️ Edit mistakes
- 🗑️ Delete mistakes
- 🤖 Automatic error detection
- 📂 Automatic error categorization
- 📊 Dashboard statistics
- 📈 Error visualization charts
- 📝 Activity logging
- 💾 Database backup system
- 🧪 Unit testing
- ⚙️ Configuration management

---

## 🛠️ Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
- Logging
- Pytest
